# codex-awake

Локальная утилита для продолжения работы Codex Desktop после завершения CI или фоновой задачи. Пока задача выполняется, ожиданием занимается обычный код без вызовов модели.

**Статус: проектирование.** Выбран Rust backend + NATS JetStream. В репозитории пока документация и результаты исследования; устанавливаемой программы нет. Сквозное пробуждение установленного Desktop ещё предстоит подтвердить.

Предлагаемый путь события:

```text
CI / локальная задача → адаптер источника → NATS JetStream
                                            ↓
                                   Rust delivery worker
                                            ↓
                                  адаптер Codex → исходный чат
```

Адаптеры и delivery worker — части одной Rust-службы. `nats-server` — отдельный локальный процесс. Начинаем с macOS, учитываем перенос на Linux и Windows.
