# Process watch

## Назначение

Наблюдать завершение уже запущенного локального процесса.

## Границы ответственности

Модуль идентифицирует экземпляр процесса, подписывается на завершение и передаёт факт завершения backend. Не запускать, не перезапускать и не останавливать наблюдаемую команду. Не выбирать чат и не формировать инструкцию продолжения.

Не включать получение exit code, stdout и stderr в первый контракт. Завершение не классифицировать как успех или ошибку команды.

- [Привязка процесса](operations/attach-process.md).
- [Ожидание завершения](jobs/observe-process.md).
- [Настройки](settings.md).
- [Кэши](caches.md).

## Зависимости

Использовать средства ОС для идентификации и уведомления о завершении. Сохранение результата передавать [backend](../backend/README.md). Первой платформой является macOS; адаптеры других ОС не специфицированы.
