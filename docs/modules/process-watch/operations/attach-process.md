# Привязка процесса

Статус: неполный контракт; S4. Способ идентификации и атомарная граница подписки не выбраны.

## Метод

Внутренняя операция `process-watch`, вызываемая при регистрации и восстановлении.

## Описание

Связать наблюдение с конкретным экземпляром локального процесса.

## Ресурсы

Средства идентификации процессов и подписки на завершение macOS. Конкретный OS API ещё не выбран.

## Входные параметры

| Название | Тип | Обязательность | Описание |
|---|---|---|---|
| `pid` | Положительное целое | Да | Идентификатор процесса в ОС |
| Сохранённая идентичность | Структура; схема не определена | Только при восстановлении | Прежний экземпляр, к которому разрешено вернуться |

## Выходные параметры

Идентичность экземпляра процесса и ресурс событийного наблюдения. Физический формат и срок владения ресурсом определить в S4.

## Результат в случае успеха

Наблюдение связано с проверенным экземпляром процесса. Повторное использование того же PID другим процессом не должно менять адресата наблюдения.

## Результат в случае ошибки

Различать отсутствие процесса, отсутствие прав, несовпадение сохранённой идентичности и невозможность создать подписку. Не трактовать отсутствие процесса как успешную привязку.

## Алгоритм работы

Приостановлен до S4: требуется выбрать механизм, закрывающий гонку между проверкой идентичности и установкой подписки. Не заменять его последовательностью «проверить PID, затем подписаться» без обработки завершения и переиспользования PID между этими действиями.

Обычный `waitpid` не считать универсальным способом наблюдения чужого процесса: его контракт относится к дочерним процессам ([Apple waitpid(2)](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man2/waitpid.2.html)).

## Ошибки

Коды и представление ошибок определить после выбора OS API; не выдавать отказ в доступе за завершение процесса.
