# Регистрации и состояния доставки

Статус: неполная физическая схема, S1. Хранение очереди effectum в файловой SQLite утверждено; размещение прикладных регистраций и журнала доставки относительно базы effectum ещё не определено.

## Сохраняемые данные

| Запись | Обязательное содержание |
|---|---|
| Регистрация | Идентификатор ожидания, ключ повторной регистрации, идентичность процесса, исходный чат, инструкция продолжения, состояние отмены |
| Доставка | Идентификатор доставки, связь с ожиданием и событием, состояние попытки, подтверждение приёма либо причина неопределённости/ошибки |

Данные регистрации должны переживать падение службы. Не изменять целевой чат или continuation при повторе той же регистрации с другим содержимым без явно определённой операции изменения.

## Состояния доставки

Следующие имена сохраняют терминологию проекта; физическая сериализация не утверждена.

| Состояние | Значение |
|---|---|
| `pending` | Внешняя отправка ещё не началась |
| `dispatching` | Право отправки зафиксировано; внешний приём может произойти |
| `accepted` | Получено подтверждение приёма Codex |
| `retry_wait` | Доказан неприём, повтор отложен |
| `delivery_unknown` | Возможный приём не подтверждён и не опровергнут |
| `cancelled` | Отправка подавлена отменой до её начала |
| `needs_attention` | Автоматическое продолжение остановлено из-за ошибки |

`accepted` не означает, что агент завершил поручение. Не переходить из `delivery_unknown` в повторную отправку без доказательства неприёма либо отдельного решения пользователя с обозначением риска дубля.

## Незавершённая физическая схема

До завершения операций определить таблицы прикладного состояния, ключи и ограничения, точные SQLite-типы и обязательность каждого поля, кодирование, timestamps, сроки хранения, миграции, границы транзакций и полные таблицы записей для каждой операции. Определить размещение этих таблиц относительно базы effectum; не предполагать общую транзакцию регистрации и постановки job без подтверждения поддерживаемого API библиотеки. Не считать таблицу содержания выше физической схемой.
