# Настройки

Статус: контракт настроек не завершён; зависит от S1, S2 и S5 в [индексе модулей](../index.md).

До завершения контракта не фиксировать имена конфигурационных ключей или неявные значения по умолчанию. Для каждой настройки определить:

| Название | Тип | Обязательность | Значение по умолчанию | Описание |
|---|---|---|---|---|

Необходимо определить путь к файлам SQLite, предел ожиданий и размера continuation, параллелизм worker, таймаут выполнения job, число и задержки повторов, политику восстановления effectum и срок хранения завершённых задач. Определить режим синхронизации SQLite и занятости записи для выбранной версии библиотеки. Параметры очереди описывать в [контракте effectum](queue/README.md), без дублирования.
