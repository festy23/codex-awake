# Настройки

Статус: контракт настроек не завершён; зависит от S1, S2 и S5 в [индексе модулей](../index.md).

До завершения контракта не фиксировать имена конфигурационных ключей или неявные значения по умолчанию. Для каждой настройки определить:

| Название | Тип | Обязательность | Значение по умолчанию | Описание |
|---|---|---|---|---|

Необходимо определить параметры подключения и аутентификации NATS, предел ожиданий и размера continuation, таймауты операций хранения, длительность и число повторов доставки. Настройки ресурсов stream и consumer должны принадлежать [JetStream](jetstream/README.md), без дублирования в конфигурации backend.
