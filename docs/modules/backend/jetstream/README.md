# Ресурсы JetStream

Статус: физическая схема не завершена; решения S1 и S2 в [индексе модулей](../../index.md).

| Ресурс | Документ |
|---|---|
| Поток событий завершения процесса | [events.md](events.md) |
| Consumer доставки | [consumer.md](consumer.md) |
| Регистрации и состояния доставки | [state.md](state.md) |

Ресурсы должны сохраняться между перезапусками службы и брокера. Подтверждение публикации брокером, запись состояния доставки и приём Codex не считать общей транзакцией. Не заявлять гарантию однократного внешнего действия на основании дедупликации брокера.

До определения физической схемы не создавать stream, consumer или KV bucket с параметрами по умолчанию. Описания ниже задают требования к ресурсам, но не являются готовой конфигурацией NATS.
