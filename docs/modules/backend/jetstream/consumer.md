# Consumer доставки

Статус: неполная спецификация ресурса, S2.

## Назначение

Выдавать сохранённые события backend для доставки и учитывать подтверждение их обработки после перезапуска обработчика.

## Подтверждение

Не подтверждать обработку события до устойчивой записи результата по его доставке. При повторной выдаче проверять состояние доставки до обращения к Codex. Уже принятую доставку повторно не отправлять.

Неоднозначную попытку нельзя повторять только потому, что брокер выдал сообщение снова. При исчерпании повторов сохранять видимое состояние, требующее разбора; достижение broker-лимита само по себе не заменяет эту запись.

## Незавершённая физическая схема

Необходимо определить имя durable consumer, фильтр subjects, способ получения сообщений, AckPolicy, AckWait, MaxDeliver, backoff и предел параллельных сообщений. Выбрать единственного владельца планирования повторов: consumer либо backend с устойчивым расписанием. До выбора не задавать конкретный порядок ack/NAK для временной ошибки.
