# Доставка события

Статус: неполный контракт; S1, S2 и S3.

## Описание

Передать факт завершения процесса в исходный чат Codex.

## Запуск

Выдача события [consumer доставки](../jetstream/consumer.md).

## Входные параметры

| Название | Тип | Обязательность | Описание |
|---|---|---|---|
| Событие завершения | Запись по схеме events | Да | [Контракт события](../jetstream/events.md) |

## Результат

Устойчивое состояние доставки: принята, отменена до отправки, отложена после доказанного неприёма, имеет неизвестный исход либо требует разбора.

## Ресурсы

- [Consumer](../jetstream/consumer.md).
- [Регистрации и доставки](../jetstream/state.md).
- [Отправка результата Codex](../../codex-delivery/operations/submit-result.md).

## Алгоритм работы

Ниже заданы ограничения порядка. Полный алгоритм с ключами чтений, полями записей, CAS и ack/NAK приостановлен до S1–S3.

1. По регистрации из события определить исходный чат, continuation, отмену и сохранённый результат доставки.
2. Если доставка уже `accepted`, не обращаться к Codex повторно. Если отмена выиграла гонку до отправки, подавить отправку. Если сохранена неопределённая попытка, не отправлять заново.
3. До внешнего вызова устойчиво зафиксировать `dispatching`, исключив одновременное получение права отправки другим обработчиком.
4. Вызвать `submit-result` с исходным чатом, continuation и фактом завершения процесса.
5. Сохранить результат:
   - подтверждённый приём — `accepted` и receipt;
   - доказанный неприём при временной ошибке — `retry_wait` в пределах ещё не выбранной политики;
   - возможный приём без подтверждения — `delivery_unknown`;
   - постоянная ошибка или исчерпание повторов — `needs_attention`.
6. Применить подтверждение consumer только после сохранения результата. Для отложенного повтора сначала должен существовать устойчивый способ его возобновления.

Если сохранение ответа Codex не подтверждено, не классифицировать попытку как безопасную для повтора. Конкретные действия при отсутствующей регистрации, невалидном событии и конфликте обновления определить вместе с физической схемой.
