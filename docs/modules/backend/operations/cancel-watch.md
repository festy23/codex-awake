# Отмена ожидания

Статус: неполный контракт; S1 и S5.

## Метод

Внутренняя операция отмены. Внешний протокол не определён.

## Описание

Подавить ещё не начавшуюся доставку по регистрации.

## Ресурсы

- [Регистрация и доставка](../jetstream/state.md).
- Подписка [process-watch](../../process-watch/README.md).

## Входные параметры

| Название | Тип | Обязательность | Описание |
|---|---|---|---|
| `watch_id` | Строка | Да | Отменяемое ожидание |

## Выходные параметры

Формат ответа не определён. Ответ должен различать подтверждённую отмену до отправки и ситуацию, когда отправка уже могла начаться.

## Результат в случае успеха

Отмена, зафиксированная раньше перехода доставки в `dispatching`, должна подавлять отправку. Не завершать наблюдаемый процесс и не отзывать принятое Codex сообщение.

## Результат в случае ошибки

Если результат фиксации неизвестен, не подтверждать отмену. Поведение для отсутствующего `watch_id` определить в S5.

## Алгоритм работы

Точный алгоритм приостановлен до определения S1. Отмена и переход в `dispatching` должны использовать один механизм упорядочивания. Если выиграла отмена, отправка запрещена; если выиграл переход в `dispatching`, ответ не должен обещать подавление внешнего вызова. Отключение наблюдения выполнять после устойчивой фиксации отмены.

## Ошибки

Определить формат ошибок отсутствующего ожидания, недоступного хранилища и неизвестного результата записи вместе с S5.
