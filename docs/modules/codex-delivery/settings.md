# Настройки

Статус: контракт не завершён; зависит от выбора транспорта S3 в [индексе](../index.md).

| Название | Тип | Обязательность | Значение по умолчанию | Описание |
|---|---|---|---|---|

Для прямого RPC `thread/queue/add` определить адрес или путь общего App Server, обслуживающего Desktop, способ доступа, таймаут отправки, допустимые размеры сообщения и версии протокола. Не задавать произвольный endpoint или путь к CLI как уже поддерживаемую конфигурацию. Не предусматривать запуск дополнительного App Server как резервный способ доставки.
