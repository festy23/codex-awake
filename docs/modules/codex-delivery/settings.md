# Настройки

Статус: частичный контракт S3 в [индексе](../index.md).

| Название | Тип | Обязательность | Значение по умолчанию | Описание |
|---|---|---|---|---|
| Порт общего App Server | Целое число от 1 до 65535 | Да | Не определено | Использовать одно постоянное значение для App Server, Desktop и Awake, в том числе после перезапуска. |

При каждом запуске общего App Server открывать TCP listener на `127.0.0.1` и настроенном порту. Если ОС отклонила открытие из-за занятого адреса, завершить попытку запуска с явной ошибкой конфликта порта с указанием адреса и номера порта. Не освобождать порт принудительно, не выбирать другой порт автоматически и не направлять сообщение процессу, занявшему порт. Успешная привязка открывает listener; принадлежность сервера исходному Desktop требует отдельной проверки.

Для S3 остаётся определить номер порта, способ задания адреса при обычном запуске Desktop, проверку сервера, авторизацию клиентов, таймаут отправки, пределы сообщения и совместимые версии. Не запускать дополнительный App Server как резервный способ доставки.
