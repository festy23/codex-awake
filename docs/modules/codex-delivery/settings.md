# Настройки

Статус: контракт не завершён; TCP WebSocket на loopback-адресе выбран. Параметры общего endpoint и настройки Desktop зависят от S3 в [индексе](../index.md).

| Название | Тип | Обязательность | Значение по умолчанию | Описание |
|---|---|---|---|---|

Для прямого RPC `thread/queue/add` определить URL общего локального WebSocket App Server, обслуживающего Desktop, способ доступа, таймаут отправки, допустимые размеры сообщения и версии протокола. Не задавать произвольный endpoint, порт или путь к CLI как уже поддерживаемую конфигурацию. Не предусматривать запуск дополнительного App Server как резервный способ доставки.
