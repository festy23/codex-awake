# Codex delivery

## Назначение

Передавать факт завершения процесса в исходный чат Codex Desktop вместе с заранее разрешённым продолжением.

## Границы ответственности

Модуль адресует конкретный чат и классифицирует результат приёма. Не выбирать другой чат при ошибке и не запускать отдельного inference-агента вместо Desktop. Не изменять настройки безопасности чата и не обходить остановку пользователя.

Использовать прямой RPC `thread/queue/add` к App Server, обслуживающему исходный чат. Не запускать дополнительный App Server для передачи сообщения через общее хранилище. Не подменять RPC внутренним IPC Desktop.

- [Отправка результата](operations/submit-result.md).
- [Настройки](settings.md).
- [Кэши](caches.md).

## Зависимости

Использовать App Server API Codex с доступным общим endpoint для Desktop и клиента. Конкретный транспорт и совместимые версии ещё не определены. Политика повторов и сохранение состояния принадлежат [backend](../backend/README.md).
