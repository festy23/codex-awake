# Модули

Статус: проект. Это логические границы внутри Rust-программы, а не набор отдельных микросервисов.

| Модуль | Основной документ | Подробности |
|---|---|---|
| Backend | [Границы](backend/README.md) | [Жизненный цикл](backend/lifecycle.md), [данные](backend/data.md) |
| Источники | [Адаптеры задач](sources/README.md) | CI, replay, локальные процессы |
| Codex delivery | [Контракт доставки](codex-delivery/README.md) | Транспорт, подтверждение, неоднозначность |

Общие состояния и идентификаторы определяет backend. Источник не выбирает чат. Транспорт Codex не устанавливает политику повторов независимо от состояния доставки.
