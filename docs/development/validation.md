# Проверка проекта

Статус: план проверок. Тесты нового backend ещё не созданы и не запускались.

## Документация

Проверить локальные Markdown-ссылки, статус каждой спецификации, соответствие принятым ADR и отсутствие секретов/локальных персональных путей. Выполнить `git diff --check`; для первого коммита проверить staged diff. Несогласованные параметры перечислить в реестре решений, не прятать в примерах.

## Критерии реализации

| Проверка | Необходимое наблюдение |
|---|---|
| Регистрация и рестарт | Ожидание сохранилось, повтор с тем же ключом не создаёт дубль |
| Повтор события | Уже принятая доставка не отправляется повторно |
| Worker crash до/после отправки | Соблюдены переходы, неоднозначность не превращается в слепой retry |
| Broker crash | Состояние восстанавливается согласно выбранной гарантии диска |
| Потеря питания/OS crash | Проверяется отдельно от завершения процесса; предел гарантии задокументирован |
| Заполненный stream/диск | Ошибка видна, необработанные события не вытесняются тихо |
| Потеря подписки | Replay либо сверка конкретного запуска, без повторного запуска CI |
| Отмена и гонка отправки | Отмена до `dispatching` подавляет отправку; после границы показан честный результат |
| Две задачи/два чата | Нет смешения адресатов и continuation |
| Неизвестный приём Codex | Нет автоматической повторной отправки без доказательства |
| Ожидание | Нет запросов модели, даже при сетевых reconnect/retry |
| Desktop end-to-end | После завершённого хода именно исходный чат самостоятельно продолжает работу |

## Порядок получения доказательств

Сначала проверить транспорт Desktop на безвредном результате. Затем описать точные контракты и реализовать domain/storage с искусственным транспортом. После этого проверить перезапуск локальных служб и выбранный CI-адаптер. В финале повторить сквозной сценарий с реальным источником.

Mock-тест подтверждает наш алгоритм, но не совместимость Desktop. Для каждого сквозного результата сохранять версии, сценарий и наблюдения без личной переписки и credentials. Без проверки восстановления источника нельзя обещать доставку событий, случившихся во время сна Mac.
