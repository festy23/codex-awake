# Локальная инфраструктура

Статус: проект. Установщик и конфигурации служб ещё не созданы.

## Процессы и хранение

Предлагаются два пользовательских процесса: `nats-server` с файловым JetStream и Rust-служба codex-awake. На macOS ими управляют два LaunchAgent. Docker и внешняя VM для первой версии не требуются.

Данные брокера размещаются в постоянном пользовательском каталоге вне репозитория и временных директорий. Логи ограничиваются по размеру и сроку; секреты, содержимое переписок и полные результаты задач в диагностические логи не записываются.

NATS слушает loopback, доступ ограничивается учётными данными локальной установки. Loopback сам по себе не изолирует других локальных пользователей. Порты, права файлов и способ передачи credentials необходимо определить до установки.

## Запуск и восстановление

Служба переносит недоступность брокера при старте: переподключается с ограниченной частотой, не создаёт вторую очередь и не теряет старую конфигурацию. Надзор ОС перезапускает упавшие процессы с защитой от цикла частых падений.

Намеренное отключение должно выключать регистрацию службы в надзоре. Обновление останавливает отправку, сохраняет данные, проверяет совместимость состояния и только затем меняет бинарники. Не удалять очередь как способ починить запуск.

Конкретные параметры launchd и блокировка второго экземпляра выбираются и проверяются в D7. Инструкции установки публикуются после такой проверки; пока runnable-команд нет.

## Платформы

| Платформа | Планируемый надзор | Статус |
|---|---|---|
| macOS | Пользовательские LaunchAgent | Первая целевая платформа |
| Linux | Пользовательский systemd либо явно поддерживаемая альтернатива | Последующий порт |
| Windows | Выбор между службой и запуском в пользовательской сессии | Последующий порт |

Пути, надзор и управление деревом процессов находятся за платформенными границами. Работа с чатом Desktop может зависеть от пользовательской сессии; системная служба Windows не считается автоматически подходящей.

## Ограничения

Один локальный брокер и один диск не дают высокой доступности. Во время сна Mac обработка приостанавливается. После пробуждения служба переподключается, а источник восстанавливает события лишь в пределах своих возможностей. Гарантии file storage определены в [модели данных](../../modules/backend/data.md).
