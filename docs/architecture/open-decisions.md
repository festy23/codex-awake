# Открытые решения

Статус: рабочий реестр проекта. Эти пункты блокируют соответствующую реализацию, но не написание независимых разделов.

| ID | Решение | Текущий кандидат | Как закрыть вопрос |
|---|---|---|---|
| D1 | Доставка в исходный Desktop chat | Штатная очередь Codex; `toolOutput` как альтернатива | Сквозной тест на зафиксированной версии Desktop: завершённый ход, точный chat ID, автономное продолжение, busy/cold/interrupted случаи |
| D2 | Первый CI и канал событий | TeamCity либо выбранный пользователем CI | Проверить доступный API, подписку/webhook, доступность Mac из CI, replay и сверку статуса |
| D3 | Состояние и ресурсы JetStream | KV для ожиданий/доставок, stream для событий | Зафиксировать схемы, CAS, дедупликацию, ack, лимиты и поведение при заполнении |
| D4 | CLI → локальная служба | Локальный IPC либо ограниченный доступ к NATS | Выбрать один канал, авторизацию, совместимость версий и ошибки |
| D5 | Политики времени и хранения | Ограниченные повторы, сохранение спорных доставок | Определить дедлайны, TTL, backoff, MaxDeliver, лимиты payload и диска без тихой потери событий |
| D6 | Локальные процессы после падения | Отметить неизвестный результат без повторного запуска | Определить владельца процесса, обработку потомков и способ получить финальный результат |
| D7 | Установка и обновление | Два LaunchAgent, бинарные релизы без Docker | Проверить упаковку, версии NATS, миграцию состояния, rollback и удаление |
| D8 | Доказательство устойчивости диска | File storage JetStream | Выбрать политику синхронизации и отдельно проверить process crash и power loss |
| D9 | Контекст и политика продолжения | Сохранённая инструкция и лимит цикла | Определить формат, отмену, смену указаний пользователя и завершение работы агентом |

D1 проверяем первым: без доступного транспорта очередь не решает главную задачу. До этого не обещаем рабочее пробуждение Desktop и не проектируем установщик вокруг непроверенного способа подключения.

Решение закрывается ссылкой на утверждённый контракт или ADR и, если вопрос экспериментальный, на воспроизводимый результат. Выбор кандидата в таблице не считается утверждением.
